# Ejercicio 4: Interacción Persona-Ordenador

## Principios del diseño interactivo

A continuación se describen brevemente los principales principios del diseño interactivo junto con un ejemplo de cada uno.

| Principio | Descripción | Ejemplo |
|---|---|---|
| **Visibilidad** | Las opciones y acciones importantes deben ser fáciles de encontrar y entender. | En una tienda online, el botón de **"Comprar"** debe estar claramente visible. |
| **Retroalimentación (feedback)** | El sistema debe informar al usuario de lo que está ocurriendo después de realizar una acción. | Al pulsar **"Enviar"**, aparece un mensaje indicando **"Mensaje enviado correctamente"**. |
| **Consistencia** | Los elementos que realizan funciones similares deben funcionar y verse de la misma manera en toda la aplicación. | Si el botón de **"Guardar"** es azul y está situado arriba a la derecha, debería mantenerse igual en toda la aplicación. |
| **Affordance** | El diseño debe indicar cómo se puede utilizar un elemento. | Un botón con apariencia de botón invita a hacer clic sobre él. |
| **Prevención de errores** | El diseño debe evitar que el usuario pueda cometer errores siempre que sea posible. | Un formulario no permite enviar una fecha de nacimiento con un formato incorrecto. |
| **Control del usuario** | El usuario debe controlar las acciones que realiza y tener opciones para deshacerlas cuando sea posible. | Una aplicación de edición de texto permite deshacer una acción mediante **Ctrl + Z**. |
| **Flexibilidad y eficiencia** | El sistema debe adaptarse tanto a usuarios principiantes como a usuarios con más experiencia. | Un programa permite realizar una acción mediante un botón, pero también mediante un atajo de teclado. |
| **Simplicidad** | La interfaz debe evitar elementos innecesarios y mostrar únicamente la información que el usuario necesita. | Una aplicación de calculadora muestra los botones necesarios sin añadir opciones que no se utilizan habitualmente. |
| **Reconocimiento antes que recuerdo** | El usuario no debería tener que memorizar información para utilizar la aplicación. | Un menú muestra directamente las opciones disponibles en lugar de obligar al usuario a recordar comandos. |
