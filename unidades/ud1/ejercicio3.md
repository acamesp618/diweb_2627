# Ejercicio 3: Diferencia entre UI y UX

## Conceptos

### Interfaz

Es el medio físico o digital que permite la comunicación entre una persona y una máquina. Por ejemplo, la pantalla de un cajero automático o el volante de un coche.

### UI (User Interface)

Es el aspecto visual y los elementos interactivos con los que el usuario toca o ve una pantalla, como los botones, los colores, las letras y los iconos.

### UX (User Experience)

Es cómo se siente una persona al usar un producto y lo fácil o difícil que es lograr su objetivo.

---

## Ejemplos

### Ejemplo de UI

El diseño visual de la pantalla de reproducción de Spotify, que muestra el botón de pausa en verde brillante, la carátula del disco centrada y una barra de progreso deslizante.

### Ejemplo de UX

El proceso completo de Spotify al escuchar una playlist con reproducción automática. No hace falta estar pulsando el botón **"Siguiente"** para pasar de canción.
