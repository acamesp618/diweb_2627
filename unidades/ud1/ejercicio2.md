# Ejercicio 2: El diseño web en la actualidad

## Características del diseño web actual

### 1. Fuentes

Las páginas web utilizan diferentes tipos de letra para mejorar la lectura y darle personalidad al diseño. Actualmente se utilizan muchas fuentes sencillas y fáciles de leer como **Roboto, Open Sans o Montserrat**.

**Ejemplo:** Google utiliza fuentes sencillas y claras para facilitar la lectura de sus páginas.

---

### 2. Títulos cada vez más grandes

Los títulos principales suelen ser cada vez más grandes para llamar la atención del usuario y dejar claro cuál es el contenido más importante de la página.

**Ejemplo:** Una página de una tienda de ropa puede poner **"Nueva colección"** con un tamaño de letra muy grande en la página de inicio.

---

### 3. Imágenes cada vez más grandes

Las imágenes ocupan cada vez más espacio porque permiten mostrar rápidamente el contenido y hacen que una página sea más visual y atractiva.

**Ejemplo:** Una tienda de ropa puede utilizar una fotografía grande de una modelo con la nueva colección como imagen principal.

---

### 4. Gráficos vectoriales

Son imágenes que pueden aumentar o reducir su tamaño sin perder calidad. Se utilizan mucho en logos, iconos e ilustraciones.

**Ejemplo:** Un logotipo creado en formato SVG puede verse correctamente tanto en un móvil como en una pantalla grande.

---

### 5. Modo oscuro

El modo oscuro cambia los colores claros de una página por colores oscuros. Puede resultar más cómodo para utilizar una web en lugares con poca luz.

**Ejemplo:** YouTube permite utilizar su página en modo oscuro.

---

### 6. Degradados

Los degradados consisten en mezclar dos o más colores de forma progresiva. Se utilizan para dar un aspecto más moderno y visual a las páginas.

**Ejemplo:** Un botón puede tener un degradado que vaya del azul al morado.

---

### 7. Neumorfismo y minimalismo

El **neumorfismo** utiliza sombras y formas suaves para crear una sensación de profundidad. El **minimalismo** intenta utilizar solamente los elementos necesarios, evitando sobrecargar la página.

**Ejemplo:** Una página puede tener un fondo sencillo, pocos elementos y botones con sombras suaves.

---

### 8. Responsive

El diseño responsive permite que una página web se adapte automáticamente a diferentes tamaños de pantalla, como ordenadores, tablets y móviles.

**Ejemplo:** Una web que en el ordenador muestra un menú completo y en el móvil lo convierte en un menú desplegable.

---

### 9. Scrolling design

#### Scroll infinito

Consiste en cargar nuevo contenido automáticamente cuando el usuario llega al final de la página, sin tener que cambiar de página.

**Ejemplo:** Instagram carga nuevas publicaciones mientras seguimos bajando.

#### Efecto parallax

Es un efecto en el que diferentes elementos de la página se mueven a distintas velocidades cuando hacemos scroll, creando sensación de profundidad.

**Ejemplo:** Una página puede tener una imagen de fondo que se mueve más lentamente que el texto al bajar.

---

### 10. Microinteracciones

Son pequeñas animaciones o cambios que ocurren cuando el usuario realiza una acción. Sirven para indicar que la página ha respondido a esa acción.

**Ejemplo:** Cuando pulsamos el botón de "Me gusta", el corazón cambia de color o realiza una pequeña animación.

---

### 11. WebXR (AR y VR)

WebXR permite utilizar tecnologías de **realidad aumentada (AR)** y **realidad virtual (VR)** directamente desde el navegador.

**Ejemplo:** Una tienda de muebles puede permitirnos ver cómo quedaría un sofá en nuestra habitación utilizando la cámara del móvil.

---

### 12. WebGL

WebGL permite crear gráficos y elementos 3D que se ejecutan directamente en el navegador.

**Ejemplo:** Una página web puede mostrar un modelo 3D de un coche que podemos girar y observar desde diferentes ángulos.

---

### 13. SPA (Single Page Application)

Son aplicaciones web que funcionan principalmente en una sola página. Cuando cambiamos de sección, no es necesario cargar una página completamente nueva.

**Ejemplo:** Gmail funciona de una forma parecida, ya que podemos cambiar entre correos y diferentes apartados sin recargar toda la página.

---

### 14. Aplicaciones web progresivas (PWA)

Las PWA son páginas web que pueden ofrecer características parecidas a una aplicación móvil, como instalarse en el dispositivo y funcionar parcialmente sin conexión.

**Ejemplo:** Google Maps puede permitir instalar su página como una aplicación en el móvil.

---

### 15. WebAssembly

WebAssembly permite ejecutar código de alto rendimiento dentro del navegador. Se utiliza cuando una aplicación necesita realizar operaciones más complejas y rápidas.

**Ejemplo:** Puede utilizarse en videojuegos que funcionan directamente desde el navegador.

---

### 16. Búsqueda y navegación por voz

Cada vez existen más páginas y aplicaciones que permiten buscar información utilizando comandos de voz.

**Ejemplo:** Podemos utilizar el micrófono para decir "buscar zapatillas deportivas" en una tienda online.

---

### 17. Inteligencia artificial (IA)

La inteligencia artificial se utiliza en las páginas web para ofrecer funciones como asistentes virtuales, recomendaciones, generación de contenido o personalización.

**Ejemplo:** Una tienda online puede recomendar productos según las búsquedas y compras anteriores del usuario.

---

### 18. Frameworks JavaScript: Angular, React y Vue

Son herramientas que facilitan la creación de aplicaciones web modernas e interactivas utilizando JavaScript.

**Ejemplo:** Una aplicación web de una tienda online puede utilizar React para crear el carrito de compra y actualizarlo sin tener que recargar la página.

---

### 19. Frameworks CSS: Bootstrap y Foundation

Son herramientas que proporcionan estilos y componentes preparados para facilitar el diseño de páginas web, especialmente diseños responsive.

**Ejemplo:** Con Bootstrap podemos crear rápidamente botones, menús, formularios y diseños adaptados a móviles.

---

### 20. Hero section

Es la sección principal que aparece normalmente en la parte superior de una página. Suele incluir una imagen, un título y un mensaje para llamar la atención.

**Ejemplo:** Una web de una asociación puede tener una imagen grande con el texto **"Luchando por cada historia"** y un botón de **"Conócenos"**.

---

### 21. CTA (Call To Action)

Es un elemento que intenta conseguir que el usuario realice una acción concreta, normalmente mediante un botón.

**Ejemplo:** Botones como **"Comprar ahora"**, **"Registrarse"**, **"Contacta con nosotros"** o **"Más información"**.

---

## ¿Por qué los logos se están volviendo cada vez más planos?

Los logos se están haciendo más planos porque actualmente tienen que verse correctamente en muchos tamaños y dispositivos diferentes, especialmente en móviles y redes sociales.

Los diseños con muchos detalles, sombras o efectos pueden resultar difíciles de ver cuando el logo aparece en un tamaño pequeño. Por eso muchas empresas utilizan diseños más simples, limpios y fáciles de reconocer.

**Ejemplo:** Un logo sencillo puede verse perfectamente tanto en una página web como en el pequeño icono de una aplicación móvil.
