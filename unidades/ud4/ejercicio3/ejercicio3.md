# EJERCICIO 3: “Mismo Texto, Diferente Emoción”

**Tarea:** Aplicar a un mismo titular una fuente Sans-Serif moderna y una Serif clásica. Explicar en 2 frases en el Portfolio qué tipo de emoción transmite cada una y en qué tipo de negocio web la usarías.

### 1. Sans-Serif Moderna (ej. Roboto)

> **«Innovación y confianza para tu futuro»**

* **Propuesta tipográfica:** Tipografía limpia, de trazos geométricos o neo-grotescos, sin remates y con alta legibilidad en pantalla.

  > Esta tipografía transmite una sensación de vanguardia, frescura, dinamismo y cercanía tecnológica. Es ideal para negocios web del sector tech, startups, aplicaciones SaaS o agencias digitales de desarrollo web y diseño.

### 2. Serif Clásica (ej. Playfair Display)

> **«Innovación y confianza para tu futuro»**

* **Propuesta tipográfica:** Tipografía tradicional con remates o modulaciones de grosor bien definidas, evocando la caligrafía editorial de imprenta.

  > Esta fuente evoca elegancia, tradición, autoridad y la solidez propia de instituciones con trayectoria. Resulta idónea para sitios web de despachos de abogados, firmas financieras, consultoras estratégicas o marcas de lujo.
