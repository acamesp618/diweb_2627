# EJERCICIO 4: Guía de Estilo UI – The Burger Games

**Tarea:** Crear la guía de estilo para la interfaz web del próximo evento *The Burger Games* usando Figma.

* **¿Qué sensaciones transmite la paleta elegida?**

  * La paleta transmite energía, calidez y un marcado carácter festivo y competitivo. El contraste entre el rojo llama y el amarillo mostaza despierta el apetito y evoca las brasas del street food, mientras que los tonos oscuros de carbón aportan un toque urbano y moderno que eleva la experiencia visual del evento.

* **¿Cumplen los botones el contraste mínimo de accesibilidad?**

  * **Sí.** El botón principal combina fondo `#E63946` con texto `#FFFFFF`, alcanzando una relación de contraste de **4.6:1**, lo que cumple el estándar WCAG 2.1 Nivel AA (mínimo de 4.5:1 para texto normal). Además, las etiquetas sobre fondo amarillo mostaza (`#FFB703`) con texto oscuro (`#1A1A1A`) ofrecen un contraste de **10.2:1**, superando ampliamente el nivel AAA.

* **Si un nuevo desarrollador entra hoy al equipo, ¿puede maquetar la web con esta guía?**

  * **Sí.** Al disponer de tokens de color claros, una escala tipográfica estructurada con tamaños y *line-heights* definidos, y especificaciones técnicas precisas para los estados de componentes interactivos, el desarrollador puede implementar las CSS Variables o Tokens directamente sin necesidad de asumir o adivinar parámetros visuales.
