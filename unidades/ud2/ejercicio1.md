| **Componente** | **Usos** | **Etiquetas HTML5** | **Ejemplos** |
|---|---|---|---|
| Cabecera | Logo, título, menú, información inicial de la página | `<header>` | [Apple](https://www.apple.com/es/) |
| Menú de navegación | Enlaces para moverse por las diferentes páginas o secciones | `<nav>` | [Wikipedia](https://es.wikipedia.org/) |
| Contenido principal | Contiene la información principal de la página | `<main>` | [MDN Web Docs](https://developer.mozilla.org/es/) |
| Sección | Agrupa contenido relacionado dentro de una página | `<section>` | [HTML5 - Wikipedia, la enciclopedia libre](https://es.wikipedia.org/wiki/HTML5) |
| Artículo | Contenido independiente como una noticia, publicación o entrada de blog | `<article>` | [BBC](https://www.bbc.com/) |
| Contenido adicional | Información relacionada con el contenido principal, como una barra lateral | `<aside>` | [EL PAÍS](https://elpais.com/) |
| Pie de página | Información final, contacto, copyright, enlaces, redes sociales, etc. | `<footer>` | [Apple](https://www.apple.com/es/) |
| División genérica | Agrupar elementos cuando no existe una etiqueta semántica más apropiada | `<div>` | |
| Figura o contenido ilustrativo | Imágenes, gráficos, diagramas u otros contenidos relacionados con el texto | `<figure>` | |
| Título o encabezado | Títulos y subtítulos para organizar el contenido | `<h1>` - `<h6>` | [W3C](https://www.w3.org/) |
